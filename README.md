One dad joke, at most 200 characters, for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun.

The joke: **"I told the printer it was out of line, so it started a new line."** (64 characters)

Why this one: the pun turns on a single word — "line" — so it lands on the first read with no explaining, the setup is a father telling off a household object, and the punchline arrives at the very end. Short on purpose: the rules break exact ties on judge win rate toward the smaller text.
